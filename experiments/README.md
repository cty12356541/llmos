## 实验设计

### exp1-trap-layer：陷入层 + 预算 + 透支 + 流水（假设 1/5/4）
- **构建**：OpenAI 兼容代理（FastAPI）。agent 只持代理 key（凭证托管：真实 key 只在代理侧）；代理做预算扣减、max_tokens 硬顶、WAL 批量流水
- **判定标准**：
  1. 透明性：一个现成的 ReAct harness 不改代码、只改 base_url 即可跑通
  2. 透支物理截断：余额 100 credits 的 agent 发起预估 150 的调用 → 生成被 max_tokens 截断，账单 ≤ 余额
  3. 耗尽语义：80% 阈值收到预警信号，100% 挂起且可充值恢复
  4. 流水吞吐：批量组提交的 WAL 在 ≥5k 扣减/s 下热路径延迟增幅 < 10%
- **产出**：可运行代理 + harness demo + 基准报告

### exp2-watchdog：看门狗误报率（假设 2）
- **构建**：复用 exp1 harness；实现进展信号（新工具调用/新产物/心跳）+ 连续步相似度（n-gram 或 embedding）
- **判定标准**：正常任务集（≥10 个）误报率 < 10%；人为死循环任务检出率 100%（≤ N 步内）
- **产出**：信号实现 + 误报/检出报告

### exp3-kv-billing：KV 计费驱动对接（假设 3）
- **构建**：对同一长前缀连续调用，检查 provider usage 字段是否含缓存命中量（如 DeepSeek 的 prompt_cache_hit_tokens）及价差
- **判定标准**：能拿到"实际成本含缓存折扣"的机器可读数据 → 按驱动回报实际成本记账落地可行
- **产出**：字段实测报告 + 计费映射建议

### exp4-msg-backpressure：消息计费背压（假设 6）
- **构建**：纯模拟（无需 LLM）：N 个 agent 消息风暴，发送者预付 vs 不计费对照
- **判定标准**：预付组风暴在预算耗尽处收敛；对照组持续放大。验证背压有效性
- **产出**：模拟器 + 对比曲线/数据

## 实验结论汇总

- **exp1-trap-layer（假设 1/5/4）✅ 通过**（2026-07-25）：三假设全实证。透明性：harness 只改 base_url 跑通全链路；透支截断：max_tokens 硬顶使 `finish_reason=length` 物理截断、账单 ≤ 余额；耗尽语义：≤20% 预警头 / 429 挂起 / 充值恢复；WAL 批量组提交 5k/s 跑满、p99 增量 6.38µs（预算 3.19%）、比同步落盘快 3.3×。子任务中途停滞，README 由 Sisyphus 接管补写。详见 exp1-trap-layer/README.md。
- **exp2-watchdog（假设 2）✅ 通过**（2026-07-25）：两级制第一级可用性实证。10 正常任务误报率 0.0%（判定线 <10%）、5 空转任务检出率 100%（步数 [4,4,4,6,7]）、3 边界任务零误杀；4×4 阈值扫描给出安全区与失效边界（maxSim 0.80 起误杀慢任务，maxSteps=3 对慢任务苛刻），佐证"阈值声明进 ELF"。已知边界：mock 空转是理想化形态，语义空转归第二级语义监督；真实 API 误报率待 .env。子任务超时停滞，实验运行与 README 由 Sisyphus 接管。详见 exp2-watchdog/README.md。
- **exp3-kv-billing（假设 3）✅ mock 通过**（2026-07-25）：同前缀连续调用，缓存命中后成本 -87.6%（1284.5 → 159.5 credits）；deepseek/openai/none 三风格字段探测与降级规则被 26 测试锁定；计费映射 `uncached×全价 + cached×折扣价 + completion×全价`，exp1 旧口径是其 cached=0 特例。真实 provider 字段形态待 .env 实测（measure_real.py 就绪）。详见 exp3-kv-billing/README.md。
- **exp4-msg-backpressure（假设 6）✅ 通过**（2026-07-25）：发送者预付决定性有效。预付组风暴量在预算耗尽处精确封顶（delivered == budget，原子扣减）；对照组永不收敛，线性放大（72k–190k）。预付保护的本质是消费端信噪比：预算 2k 时 SNR=0.666 且风暴死后恢复 1.0，对照组 SNR 全程 0.02–0.05。机制背压（收件箱）单独只限速不限量（B1 仍 72k），必须与经济背压组合。详见 exp4-msg-backpressure/README.md。
