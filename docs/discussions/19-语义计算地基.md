# 议题 19：语义计算的地基——计算机底层方法论全景与可迁移清单

> 轮次：第 19 轮（2026-07-25）
> 用户问题：通用系统与现代系统的底层基础抽象有哪些（含网络、分布式等一切计算机底层基础设施），哪些可被参考进 LLM runtime，用于构建"非数值型、语义型"的通用计算超级框架
> 性质：回到第一性原理的地基 excavation

## 一、计算机底层抽象全景清单

### 1.1 按领域分的抽象对象

| 领域 | 底层抽象 | 解决的根本问题 |
|---|---|---|
| 计算本体 | 图灵机/λ演算/冯诺依曼架构；**存储程序（代码即数据）**；ISA；通用模拟 | 什么是可计算；一台机器模拟一切机器 |
| 存储与记忆 | 存储层级（寄存器→缓存→RAM→盘→网络）；**虚拟内存**；持久化/序列化；缓存 | 稀缺与速度的分层；无限私有内存的幻象 |
| 命名与间接 | 地址空间/指针；DNS/URI；符号链接；能力（capability）；**"计算机科学的一切问题都可用增加一个间接层解决"（Wheeler）** | 名字与实体的解耦 |
| 抽象与组合 | 函数/过程（第一个伟大抽象）；模块与**信息隐藏（Parnas）**；接口与类型；组合子（pipe/map-reduce） | 复杂度驯化；局部理解全局组装 |
| 并发与协同 | 进程/线程；锁/信号量；消息传递（CSP/Actor）；**时间与顺序（Lamport/happens-before）**；共识（Paxos/Raft）；不可能性（FLP/CAP） | 多体同时行动的秩序 |
| 网络 | **分组交换**（对电路交换的历史性胜利）；**分层**（每层只解决一个问题）；**端到端原则**（智能在边缘，网络愚笨）；尽力而为+端点可靠性 | 不可靠介质上的可靠通信 |
| 容错 | 冗余/复制/纠删码；超时/重试/**幂等**；至少一次+去重；故障检测器 | 部件会坏，系统不能坏 |
| 数据与信息 | **关系模型**（Codd：数据独立性、声明式查询）；事务 ACID/BASE；索引；**香农信息论**（熵/压缩/信道容量）；**柯氏复杂度**（算法信息论） | 数据的结构、一致与度量 |
| 语言与编译 | 形式文法；IR 与优化 pass；**类型系统即静态验证（Curry-Howard：类型即命题，程序即证明）** | 意图到执行的保真翻译 |
| 安全与信任 | 认证 vs 授权；**能力安全/最小权限**；密码学（哈希/签名/PKI/零知识）；信任模型（CA/Web-of-trust/DID） | 敌手存在下的边界 |
| 验证与评估 | 测试；形式验证/模型检查；类型即证明 | 正确性的证据 |

### 1.2 横切的抽象方法（方法论，比对象更底层）

1. **间接（indirection）**：加一层解决一切（虚拟内存、DLL、驱动、API）
2. **分层（layering）**：垂直切分关注点，每层一个谎言（协议栈、OS）
3. **信息隐藏**：接口与实现分离，变更局部化
4. **分治**：大问题拆小问题（算法、微服务、MapReduce）
5. **缓存/记忆化**：空间换时间，在每一个层级上重复出现
6. **虚拟化**：呈现一个不存在的幻象（VM、虚存、容器）
7. **共识协议**：副本间达成一致的数学结构
8. **队列与背压**：速率失配下的流控
9. **幂等与不可变**：让重试与复制安全
10. **自动资源回收（GC）**：不再使用的自动归还
11. **最终一致与和解（CRDT/merkle）**：不协调也能收敛
12. **等价与模拟**：证明两个系统算的是一回事

## 二、可迁移性三分类

### A 类：直接迁移（介质无关的协同结构）
间接/命名、分层、能力安全、背压、缓存、租约、共识结构、端到端原则、事务/托管、进程模型、并发原语。
**这些与"计算对象是 bit 还是语义"无关——它们是协同结构。** llmos v0.2 设计一直在消费 A 类（namespace/衰减/背压/租约/Raft/escrow），这解释了为什么后续议题"消耗概念而非堆积概念"。

### B 类：变换迁移（同一抽象，语义形态改变）

| 经典抽象 | 语义计算的形态 | llmos 现状 |
|---|---|---|
| 虚拟内存 | 上下文分页（已做） | ✅ 议题 6 |
| 相等（bitwise） | 相似（threshold、context 相关） | ✅ 议题 9 看门狗已用 |
| 类型（形式约束） | **语义规格**：自然语言写的契约，由模型校验而非类型检查器 | 未做 |
| 编译（语法制导翻译） | **意图制导的上下文综合**（prompt compilation：把意图编译成 context） | 未做（DSPy 等是雏形） |
| 一致性（副本相同） | **解释相容**（议题 12 的 OS 模型已部分回答：内核不管信念） | ✅ 部分 |
| GC（回收不再引用） | **遗忘**（记忆衰减/defrag；Letta sleep-time 方向） | 未做 |
| 数据库查询（精确匹配） | 语义检索（embedding 相似检索——当前弱答案） | 未做 |
| 事务（字节原子） | **语义事务**（意义层的相干原子更新） | 未做 |
| 代码评审 | 语义评审（监督 agent 裁决） | ✅ 议题 9 两级制 |

### C 类：无经典对应，必须新发明（语义计算的本元）

1. **语义原子**：意义的最小可操作单位——不是 token 不是 bit，是"命题/断言"级对象，自带 provenance 与置信度（议题 9 的 provenance 元数据是它的雏形）
2. **语义等价与规范化**：两段文本何时"同义"——意义的 canonicalization（类比代码规范化/哈希，但是 graded 而非 binary）
3. **可验证意图规格**：任务的"类型"——机器可检查的完成判据。杠杆来自生成-验证不对称（议题 9 校验器档已用，但"规格"本身没有形式）
4. **信任加权信息融合**：多源信念合并（provenance × 置信度 × 来源独立性）
5. **随机性作为一等执行语义**：议题 9 已开工（统计性容错），但"随机执行的语义学"没有经典理论可抄

## 三、理论锚点

### 3.1 意义 = 压缩：语义计算的信息论基础已经存在
柯氏复杂度/MDL/Hutter 奖品（"理解即压缩"）：**意义 = 生成模式的最短程序**。LLM 正是人类文本分布的有损压缩器：训练=压缩（把分布压进权重），采样=解压生成。所以"非数值语义计算"不是凭空造科学——它的信息论地基（算法信息论）已存在半个世纪，缺的是**系统层**（围绕压缩表示做存储、寻址、组合、验证的工程抽象）。这正是 llmos 的位置。

### 3.2 不可判定性的继承：统计验证是必然不是权宜
图灵停机问题的语义版：任意输出的语义正确性一般不可判定。推论：不存在普适的形式验证器，**统计验证（校验器/N 版本投票/监督）是理论必然**，而不是工程将就。议题 9 的容错四档因此有了理论身份：它们是不可判定性约束下的最优可行策略族。

### 3.3 符号主义的尸体：上一轮"语义计算"为什么死
1970s-2000s 的符号主义就是上一次"语义型通用计算"：语义网络、框架（Minsky frames）、描述逻辑、Cyc（手工录入数百万条常识）、SOAR/ACT-R 认知架构、语义网（RDF/OWL）、**FIPA ACL**（90 年代的 agent 通信语言标准——A2A 的前生前世）。死因一致：**语义无法被手工形式化**——规则写不完、本体对不齐、常识无穷尽。本轮成功的路径相反：语义由统计学习获得（LLM），不可形式化的部分留给模型。
**铁律：框架管结构与协同（A 类+B 类），语义的理解与生成留给统计模型（绝不试图在内核里形式化意义）。** llmos 的"内核不管信念"（议题 12）与这条铁律一致。

## 四、超级框架的通用性判据（"语义图灵完备"）

经典通用性：UTM——任何可计算函数可由一台机器模拟。
语义通用性的候选表述：**任何知识工作任务，都可表达为（Agent + Context + Tool + Channel + Memory）的有限组合**。
- 判定方法：重构测试从框架级（议题 13 的 16 模式）推广到**任务级**——"任意人类知识工作流程能否分解为这些原语的组合"
- 反方举证责任：找出一个不可分解的任务类型（候选：纯感知运动技能、真创造 vs 重组——边界争论点）

## 五、与 llmos 现状的关系

- **已建（A 类大部分 + B 类一部分）**：这正是设计"不堆概念"手感的来源
- **已开工**：随机性执行语义（议题 9）、provenance 元数据（语义原子雏形）
- **未触碰的新空间（C 类的核心三问）**：语义原子、语义规范化、意图规格——这是 v0.2 之后真正的下一个设计前沿，也是"非数值语义计算"区别于"带 LLM 的分布式系统"的本质所在
- **路线校验**：v0.2 的轨迹（先协同结构后语义本元）与历史一致——Unix 也是先把进程/文件/管道立住，语义层（应用生态）在其上长出来
