# 议题 22：语义规范化——"同义不同字"的等价判定

> 轮次：第 22 轮（2026-07-25）
> 前置：议题 21（语义原子定案：id=内容哈希只解决"字面相同"）
> 本轮任务：定义语义等价（及更广的语义关系）的表示与计算架构

## 一、问题与用途

原子的内容哈希幂等只覆盖字面相同。规范化的用途：去重（同义断言不产生冗余原子）、融合（佐证合并）、**冲突检测**（矛盾断言的发现——议题 12"分歧可见"的机制落地）、检索（找相关原子）、血缘图压缩（同一事实的多个表述归并）。

## 二、根本约束：等价是昂贵的近似判断

字面相等免费且精确；语义等价**有成本、是近似、依赖上下文、且需要模型判断**。防火墙推论：内核不能计算等价（不读 content）——等价计算必须在用户态，内核只存储与索引其结果。架构问题因此不是"怎么判等价"，而是"**等价判断的结果如何表示，使得判断可以由模型做、利用由系统做**"。

## 三、核心设计：等价断言也是原子（link atom）

"X 与 Y 同义"本身就是一个断言——它有判断者（谁判的）、时间、方法、置信度。所以它应该就是一个语义原子：

```
LinkAtom extends SemanticAtom {
  relation:  EQUIVALENT | CONTRADICTS | ENTAILS | SUPPORTS | REFINES
  endpoints: [原子 id A, 原子 id B]
  judgment:  { by: 哪个模型/服务, method: embedding|llm|human, confidence? }
}
```

设计收益：
1. **等价关系是信念流上的图，不是身份映射**——原子保持不可变，不需要 canonicalization（不必选"哪个表述是正统"）
2. **错误的等价判断用墓碑撤回**，与撤回错误断言同一套机制（议题 21 的不可变+墓碑免费复用）
3. **等价判断本身有 provenance**——"谁判的、用什么方法"可追溯；不同判断者的分歧也可表示（两个矛盾的 link atom 共存，按议题 12 的 OS 模型处理）
4. **CONTRADICTS 关系直接落地议题 12 的"分歧可见"**：矛盾断言通过 link 显式化，裁决归用户态/组织层（内核不管信念的边界保持）
5. 关系类型是**闭集小枚举**（5 个值）——结构字段不是语义形式化，与断言级别同级（防火墙不破）

## 四、等价计算的三层架构（与看门狗两级制同构）

| 层 | 机制 | 成本 | 职责 |
|---|---|---|---|
| L0 内容哈希 | 原子 id（议题 21 已定） | 免费 | 字面去重 |
| L1 embedding 粗筛 | 生产时计算 fingerprint 向量入信封（可选字段），内核提供向量索引（内核做算术不读语义） | 便宜 | 候选对生成（blocking） |
| L2 LLM 精判 | 用户态等价判定服务，对 L1 候选对做判断，产出 link atom | 贵（一次 LLM 调用） | 精确判定（matching） |

经典信息检索的 blocking+matching 模式；也与议题 9 的两级制（内核便宜过滤器+用户态语义监督）同构。**计算时机三处**：生产时（harness 发射原子前查重，源头避免冗余）、后台和解守护进程（周期性扫描候选，类比数据库 GC/merge）、按需（消费者问"这是否新"）。**等价计算是可计费变换**——L2 判断消耗 Budget（议题 8 链路自然纳入）。

## 五、边界与陷阱检查

- 内核角色：存储 link atom（只是原子）、维护向量索引（算术）、按信封字段过滤——**不做任何语义判断** ✅
- fingerprint 入信封不破防火墙：向量是"指纹"不是"内容"，内核索引指纹不等于理解内容（类比文件类型元数据）✅
- 关系枚举保持闭集小集，不开放为本体语言（RDF 死因）✅
- 语义规范化的灰度（"部分等价""在此语境下等价"）不进信封——那是判断方法的输出描述，留在 link atom 的 content 里（NL，模型可读）✅

## 六、对下游的支撑

- **意图规格（C 类 3/3）**：验证"产出是否满足规格"本质上是语义匹配——规范化的 L1/L2 判定设施直接复用为验证器基础设施
- **遗忘（B 类）**：同义原子簇是 defragmentation 的合并对象
- **融合（C 类延伸）**：EQUIVALENT/SUPPORTS 簇 + provenance = 信任加权融合的输入
- **构造性证明（议题 20）**：公理 B 的"映射"允许产出与消耗之间存在语义重叠——link atom 使变换的输入输出关系可显式陈述
