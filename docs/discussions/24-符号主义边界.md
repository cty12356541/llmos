# 议题 24：符号主义边界——框架的形式化宪法

> 轮次：第 24 轮（2026-07-25）
> 前置：C 类三问已定案（21/22/23），内核中已积累若干小闭集枚举
> 本轮任务：给"内核里允许多少形式化"立下可执行的边界规则，防止渐进滑入符号主义陷阱

## 一、问题：累积效应才是陷阱

单个看，内核中的形式化都很克制：断言级别（4 值）、验证状态（3 值）、link 关系（5 值）、规格 method（3 值）、constraints 字段。但符号主义的死因从不是一次大形式化，而是**累积**：每个枚举都诱人扩展（为什么 5 种关系不是 7 种？）、每个字段都诱人被内核逻辑"更聪明地"使用。需要的不是逐案判断，是宪法。

## 二、总规则：形式化认识论，绝不形式化语义

**formalize the epistemics, never the semantics。**

| 允许形式化（认识论/过程元数据） | 禁止形式化（语义/内容元数据） |
|---|---|
| 谁说的（provenance source） | 说的是关于什么的（主题分类/本体） |
| 怎么产生的（断言级别：工具事实/推理/推测/指令） | 内容属于什么类别（领域 taxonomy） |
| 怎么验证的（验证状态、验证方法） | 内容是否为真（内核不判真假） |
| 被谁判了什么关系（link relation + judgment provenance） | 内容的含义（内核不解析） |
| 何时失效（TTL）、多少钱（Budget） | "部分等价""语境真"的灰度语义 |

判据一句话：**我们形式化的是"知识的社会学"（生产与流通的过程），永远不形式化"知识本身"。** 现有枚举逐项过检全部合规——包括最接近边界的断言级别（它是生产者对自己产出过程的自声明，不是内核对世界的事实判断）和 link 关系枚举（它分类的是"判断"不是"内容"，判断的 provenance 在 link atom 里可查）。

## 三、新增形式化的四重测试（宪法修正案程序）

任何新形式化进内核，必须四关全过并留下决策记录：

1. **结构性**：关于过程/溯源，不关于世界事实？
2. **闭集小集**：枚举封闭且小（参考值 <7），不开放为语言？
3. **机械性**：内核逻辑只做 filter/route/gate，不做语义推理（见决策 3）？
4. **内容无关**：移除它不需要内核读 content？

任一不过 → 进用户态扩展或原子 content（NL），不进内核。

## 四、内核逻辑的边界：枚举字段上只允许机械规则

允许："只有 verified 原子进规划上下文"（对结构字段的过滤规则）；按污点级路由；按 TTL 回收。
禁止：内核从枚举值**推导新事实**——例如"两个 INFERENCE + 一个 FACT → 提升为 FACT"（这是语义推理，归用户态融合服务）；"CONTRADICTS 多于 SUPPORTS → 自动标 disputed"（这必须经由用户态判定流程产出新原子，内核不自动改写状态）。
一句话：**内核可以对信封执法，不可以对信封思考。**

## 五、陷阱预警清单（未来诱惑的形式）

1. **枚举膨胀**："5 种关系不够用，加个 PART_OF 吧"——PART_OF 是世界关系不是判断关系，直接破墙
2. **聪明内核**："内核顺手做个简单推断能省一次 LLM 调用"——这是符号主义的标准入口
3. **规格判据形式化**："把常见验收判据做成内核内置模板"——模板归用户态库（skills），内核只有 method 枚举
4. **主题索引**："给原子加主题字段方便检索"——检索索引用 embedding fingerprint（已有），主题分类是本体

## 六、用户决策（第 24 轮，2026-07-25）——形式化宪法立

| 决策点 | 拍板 | 落地形态 |
|---|---|---|
| Q1 总规则 | **形式化认识论，绝不形式化语义** | 形式化"知识的社会学"（谁说的/怎么产生/怎么验证/谁判的关系），禁止形式化"知识本身"（主题/类别/含义/真假） |
| Q2 枚举治理 | **冻结 + 四重测试** | 内核枚举集冻结；新增形式化须过四重测试（结构性/闭集小集/机械性/内容无关）+ 决策记录 |
| Q3 内核逻辑边界 | **允许简单推导**（非推荐项，用户选择） | ⚠️ 经讨论精化为可执行边界——**允许**：对结构计数的机械触发（watchdog 先例已隐含此允许：步数/相似度计数→挂起+标记），触发结果**限于进程控制面**（挂起/标记/限流/告警）；**禁止**：改写语义状态（验证状态/断言级别/关系判定）——语义状态的变更必须由用户态判定流程产出新原子（带 provenance）。判据：推导写进程状态还是写信念流。注：Sisyphus 原推荐"只执法不思考"，但 watchdog（议题 9 已定）本质就是结构计数+阈值触发，用户的选择与既有设计自洽；精化边界使"简单推导"有定义、禁区明确 |

**议题 24 关闭。** 形式化宪法三条：认识论可形式化（语义永不）、枚举冻结（四重测试+决策记录）、推导分界（机械触发可写进程状态，语义状态归用户态原子）。
