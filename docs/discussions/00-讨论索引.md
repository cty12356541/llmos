## 用户核心论点（持续累积）

1. **规模化不是空想**：可供调度的资源将持续数量级增长（类比计算机成本曲线），万级 agent 调度是必然面对的问题（第 3 轮）
2. **历史类比论**：智能体系统正在重复计算发展史——专用指令/专用系统 → 通用系统 → 现代系统；当前处于"专用系统"阶段，通用运行时（agent OS）是必然产物（第 4 轮）

## 方向修正（2026-07-23，用户指令）

**"规模是压力测试，通用才是宗旨。"** 此前讨论漂移进治理细节（计费/escrow/重授权——大型机 MVS 气质），偏离了"设计通用系统 + 讨论现代系统"的主旨。分诊归位：

| 已有内容 | 归位 |
|---|---|
| Agent/Context/Tool/Message/Topic/Blackboard、陷入层、ELF | **通用系统核心**（通用性载体） |
| 调度/tick/抢占 | 分时机制——有用，保留，但只是机制不是宗旨 |
| Budget/Policy 的治理语义（escrow/计费/重授权链） | 治理层——降级为可插拔模块（本就在用户态），不再占中心 |
| provenance/看门狗/容错机制 | 内核机制保留，表述归位为支撑设施 |

后续议题主线：**通用系统的本质** → **现代系统**（分布式/namespace/网络协议栈/云原生）。
