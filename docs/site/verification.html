DIM-01 · TOKENS (FUNGIBLE) nlos-resource

Tokens（可转移账本额度 · 输入/输出/推理分维）

纳入 ResourceAccount 封闭守恒账本：区分可见输出与推理链 token，调用前将 RESERVATION.limit 折算为 max_tokens 下发驱动截断。

DIM-02 · MONETARY CREDIT (FUNGIBLE) WAL+FULL

MonetaryCost（可转移整数最小单位 Credit）

唯一同质化货币守恒域（BUD-INT-001）：模型调价留在签名 PricingVersion，有界滞后超支优先由运维 RISK_RESERVATION.loss_bound 吸收（BUD-CONS-002）。

DIM-03 · WALL TIME & ENERGY Meter & Lease

WallTime & Energy（单调截止期与累计计量）

非同质化维度（RSM-ALG-001）：绑定 MonotonicDeadline、租约 TTL 与 energy_mJ 单调 CumulativeMeter，外部网络等待与本地 CPU 严格分列。

DIM-04 · COMPUTE CPU / FUEL ResourceGroup

ComputeCPU/Fuel（容量授权与指令步长控制器）

由层级 ResourceGroup / ResourceController 管控时间片配额、并发槽位与 Wasmtime 确定性 fuel / epoch 门限，不与货币 credit 混算。

DIM-05 · MEMORY / CONTEXT nlos-task · nlos-artifact

Memory/ContextBytes（容量租约与分级驻留）

由 nlos-artifact、nlos-semantic 与 nlos-task 协同 ResourceController 按 PINNED、CHECKPOINTABLE、RECLAIMABLE 管控容量上限与有序回收。

DIM-06 · IO / NET / ATTENTION Rate & Non-Fungible

I/O、网络窗口与非同质化人类注意力

I/O、网络带宽与扇出受窗口速率及落盘准入控制（RSM-ADMIT-001）；人类注意力由 nlos-notify NotificationBudget 非同质化节流（RSM-HUMAN-001），严禁花钱绕过。

Epistemic Plane · nlos-semantic · ADR-0006 & ADR-0023/ 02

概率执行治理与认知语义平面

内核不能消除概率模型的幻觉，但能把不确定性关进可验证的系统结构。NLOS 一方面用四道概率执行防线隔离运行时错误，另一方面通过 nlos-semantic（ADR-0006 出版回执归属、ADR-0023 VERIFIED 语义写入桥与硬门禁）把“谁主张了什么、依据哪条血缘被采信”固化为只追加签名认知图谱。

CONTROL-DOMAIN AUTHORITY VIEW & INTENT SPEC GATE · ADR-0023 VERIFIED

按 ControlDomainId 物化 AuthorityView 与 IntentSpec 硬门禁

系统不维护单一全局 verified 字段（SEM-GLOBAL-001）。AuthorityView 在不可变 TrustPolicy 与签名 SemanticCheckpoint 下按 ControlDomainId 独立性聚合成效事实，阻断同一控制者用多把密钥伪造多数派（SEM-VIEW-003）。同时 IntentSpec 强制执行非空验收条件硬门禁（ADR-0023 VERIFIED）：缺少可核验验收谓词的意图无法跨越权威提交门。

MANDATORY TAINT GUARD · NLOS-SEARCH 0x1F

向量检索强制携带 0x1F NON_AUTHORITATIVE 污点

语义相似度命中永远不等于系统权威事实。nlos-search 输出的每一条检索候选均强制烙印位掩码 0x1F NON_AUTHORITATIVE，在内核门禁处物理阻断相似片段直接充当权限凭据、账本依据或任务提交输入，使用前必须回跳权威对象重验签名与代际。

// ADR-0010 + ADR-0011: 单调衰减能力核验与跨进程签名直通（零环境特权）
pub fn verify_delegated_invocation(
  chain: &SignedCapabilityChain,
  envelope: &AuthenticatedIpcEnvelope,
  taint: TaintMask,
) -> Result<VerifiedGrant, SecurityDeny> {
  chain.verify_ed25519_signatures_and_epoch()?;      // 逐跳验签 + 代际吊销水位检查
  chain.assert_monotonic_subset()?;                  // 子能力 ⊆ 父能力，物理禁止越权放大
  envelope.verify_principal_passthrough(chain.leaf())?; // Unix Socket / Named Pipe 签名直通
  if taint.contains_unapproved_egress() {
    return Err(SecurityDeny::TaintedEgressBlocked);  // 提示词注入污点在出口处硬阻断
  }
  Ok(chain.into_verified_grant())
}
