North Star/ 01

[NLOS-GOAL-001]：启动微内核是载具，系统完整性才是终局

Windows/macOS 级别不是指第一天重写裸机硬件驱动，而是指现代操作系统的完整契约：未预见的第三方应用无需改内核即可安装运行；身份、权限、预算守恒与外部副作用由不可绕过的系统权威统一裁决；普通用户与专业开发者共享完整人机界面与长期兼容生态。

Why an OS/ 02

当模型进入计算主回路，四处底层假设同时断裂

传统应用程序默认指令确定、内存按字节寻址、本地调用可同步回滚；一旦概率模型与外部世界接入主循环，这四条假设同时失效。进程内的用户态函数库无法约束自身沙箱之外的权力与副作用，必须下沉为操作系统权威。

01 · PROBABILISTIC 概率语义断裂

模型推理天然含噪且易受外部不可信文本诱导；安全边界绝不能建立在“Prompt 嘱咐模型守规矩”之上，必须由外部 TCB 机械裁决。

02 · MEMORY HIERARCHY 上下文层次断裂

活跃注意力窗口昂贵稀缺而持久知识近乎无限；必须建立类似虚拟内存的 Context 工作集驻留、按需换页与不改逻辑读集的驱逐机制。

03 · EXTERNAL EFFECTS 外部副作用断裂

支付、发信与写库一旦越过网络即不可逆；超时或断连不等于“未执行”，必须用 EffectPermit 与 EFFECT_UNKNOWN 冻结盲目重试。

04 · MULTI-ATTEMPT 投机并发断裂

同一任务常派生并行探索或故障接管 TaskAttempt；缺乏快照读集与代际围栏，慢速旧实例必静默覆盖最新权威状态。

用户态库负责“怎么组织一次推理策略”

提示模板、思维链拓扑、角色分工、检索重排与领域工具链属于高频迭代的应用智慧。NLOS 不在内核里内置特定编排学派，而是让不同框架成为系统之上的可替换用户态程序。

系统权威裁决“谁有权在有限世界中提交什么”

主体身份、Namespace 可见域、Capability 最小权限、ResourceAccount 可转移信用封闭守恒（[BUD-ALG-001]：仅承载 Token / 金额信用）与 ResourceGroup 容量/速率控制及非可替代注意力门禁（[RSM-ALG-001] / [RSM-HUMAN-001]）、跨崩溃 WAL 账本与唯一 canonical 提交，由不可绕过的系统层统一强制。

主权域诚实判据（[NLOS-HOST-002]）

凡不能从机制上阻止用户态直接旁路外部网络、宿主文件或账本的嵌入形态，一律只能标记为 COOPERATIVE 协作模式，严禁冒充 STRICT 系统级主权。

Core Philosophy/ 03

贯穿规范、内核与桌面的五条系统轴心

这五条轴心决定了什么必须沉入 TCB、什么必须留在用户态，以及全站每一条技术声明如何接受检验。

01

自然语言是首要界面而非唯一界面

自然语言让用户直接表达目标与约束，但可信 GUI、CLI 与结构化 API 同样是一等交互面；图形与后台服务绝不被迫伪装成聊天机器人，四类入口收敛至同一契约与字节等价回执。详见 执行与控制 · 顶层编译 与 手动控制。

02

机制在内核，语义与策略在用户态

内核控制不依赖理解自然语言修辞，只机械核验句柄、签名能力、配额预留、代际号与写集冲突；Planner、工作流图与记忆压缩全部留在可替换用户态与系统服务。详见 通用内核 · 三层架构与 SABI。

03

命名即视野，能力即权限

每个进程仅拥有私有 Namespace 挂载表，不可命名的对象在该命名空间内天然不可寻址、不可行动；跨边界操作必须出示可单调衰减的 Ed25519 Capability。详见 通用内核 · 系统对象。

04

先承认不确定性，再用围栏承诺边界

系统直面模型幻觉、并发竞态与外部网络断连：内部状态用 TaskSnapshot + CommitPermit 保证唯一线性化提交，外部动作以 EffectPermit + EFFECT_UNKNOWN 阻断失控放大。详见 支撑与验证 · 随机性与围栏。

05

Claim ≤ Evidence 工程诚实纪律

规范设计、单机测试、多进程故障注入与生产运行严格分级记录；全仓 101 项声明与 169 份证据由 lint_claims.py 持续核验，绝不把设计蓝图改写为已交付事实。详见 支撑与验证 与 阶段路线 · 证据等级。

Transfer Method/ 04

三层机制迁移法：先复用成熟控制回路，再发明独创原语

依据 [PHIL-TRANSFER-001..002]，任何新抽象进入系统前必须先回答：最接近的现代系统机制是什么、哪些不变量可直接继承、模型在哪里造成了真实语义断裂。迁移的是状态机、隔离边界与失败语义，而非表面术语。

A

直接复用成熟机制（不变量与工业原语原样继承）

凡密码学、单机事务存储、异步调度与字节码沙箱已有严密工程解的领域，直接采用经受过严苛验证的机制，零重复造轮子：使用 Ed25519 非对称签名实现不可伪造的令牌与包验签（ADR-0010），以 SQLite WAL + FULL synchronous 构筑单机断电不丢账的持久权威底座，依托 Tokio M:N 运行时承载高并发异步 I/O，通过 Wasmtime fuel 与 epoch 双重中断隔离不可信插件（ADR-0015），并复用 DRR 赤字轮转公平调度与 Blake3 Merkle 抗熵树完成流量与状态对账。

Ed25519 Capability (ADR-0010) SQLite WAL + FULL sync Tokio M:N Runtime Wasmtime Fuel/Epoch (ADR-0015) DRR Fair Scheduling Merkle Anti-Entropy
B

语义适配迁移（保留系统控制回路，重写模型与任务语义）

保留传统 OS、数据库与分布式系统的骨架，针对长时异步推理与多尝试并发扩展对象语义：将传统进程/线程/协程重构为 Application → Process → AgentInstance → Fiber → Activation 五层执行模型（Issue #29）；迁移 Plan 9 进程级私有 Namespace 约束智能体可见域；将数据库 MVCC 扩展为面向多尝试竞速的 TaskSnapshot + 6 域 TaskWriteSet 冲突代数（ADR-0013）；将分片集群租约改造为分层 Cell 租约与单调 epoch fencing（ADR-0018 / ADR-0019）。

5-Layer Process/Agent/Fiber (Issue #29) Plan 9 Per-Process Namespace MVCC TaskSnapshot + 6-Domain WriteSet (ADR-0013) Hierarchical Cell Lease & Epoch Fencing (ADR-0018/0019)
C

NLOS 独创系统机制（传统 OS 与用户态框架均未覆盖的原语）

在概率模型与不可逆现实世界交界处，建立传统内核与现有 Agent 框架均缺失的原语（Issue #31/#32 横评确认该系统级生态位尚属空白）：首创 CommitPermit + EffectPermit 双重围栏与 EFFECT_UNKNOWN 未知副作用隔离态；严格依资源真实代数分离信用账本与多维控制器（v0.5 §10 / §10.1）：[BUD-ALG-001] 规定 ResourceAccount 仅持有可转移同质信用（Token / Monetary credit）并服从封闭域守恒等式 MINTED + INBOUND = AVAILABLE + RESERVATION.limit + RISK_RESERVATION.loss_bound + ESCROW + LEASE + SPENT + QUARANTINED + OUTBOUND，而 CPU、内存、I/O、网络与能耗由 ResourceGroup / ResourceController 容量、速率与单调累计包络治理（[RSM-ALG-001]），人类注意力显式定性为非可替代资源（[RSM-HUMAN-001]：经 NotificationBudget 与中断门控约束，绝不折算为可购买同质信用）；定义 SemanticEvent 双身份（内容摘要 ContentDigest 分离于事件实例 EventId）配合 0x1F NON_AUTHORITATIVE 派生检索防提权护栏；并在 Stage D 桌面层（ADR-0025 W68-R1/R2）显式与外部 Glacier 架构门户分叉，确立零眩光实心 Graphite / Paper Workstation 表面、平铺优先工作区 + 36px 任务栏 + Ctrl+Space 命令/意图面板、Z4 实心 UAC/Polkit 安全确认屏（内嵌 32×20 凹陷单色精密防伪印章）、L0–L3 四级渐进式披露与 [UI-PARITY-001] 12 域显控同构。

Honest Boundaries/ 05

2026-10-26（W68）理论极限与工程诚实边界

真正的系统工程不仅声明能保证什么，更精确划定数学上不可消除的边界与当前拓扑尚未跨越的门禁。

THEORY-LIMIT · PROMPT INJECTION & AUTHORITY

提示注入无法在语义层 100% 根除，只能由权限边界封顶

只要开放上下文同时接收指令与不可信外部输入，纯语义分类器就不存在零漏报数学保证。NLOS 不宣称“模型免疫提示注入”，而是以 私有 Namespace（[THEORY-LIMIT-004] 不可命名即不可寻址）+ 最小 Capability + Taint 污点降权 + Z4 实心系统安全确认屏 将诱导爆炸半径严格锁死在授权围栏内。

THEORY-LIMIT-001..005 · EFFECTS & EPISTEMOLOGY

黑盒工具不可证无副作用，VERIFIED 不等于客观真理

任意外部黑盒 API 在断连或超时后无法被证明未产生副作用，系统必须诚实落入 EFFECT_UNKNOWN 并冻结自动重试；同时，VERIFIED 仅代表密码学签名归属或确定性测试契约通过，绝不宣称模型推理必然符合客观事实，亦不将“拜占庭 3f+1”“意义=压缩”或“语义图灵完备”冒充为已证定理。

SCALE HONESTY · 100K_LOGICAL (634 B/NODE)

十万逻辑规模是持久任务与挂起协程，绝非十万路并发 GPU 推理

H6 实测达标的 100K_LOGICAL（单节点约 634 B/node）严格指 10 万个持久可调度 TaskNode 与挂起等待 Fiber 描述符，并将 logical / materialized / runnable / active / resident 分维计量，绝不等于 10 万个 Agent 同时占用 GPU 吐出 Token 流。
