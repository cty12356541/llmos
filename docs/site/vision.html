Constitution · Philosophy · Method

不是更大的编排框架，而是自然语言操作系统

项目最高目标是构建达到 Windows/macOS 级别的通用、现代、系统级 NLOS。确定性执行层、Agent reference monitor、控制面和单机 MVP 都只是启动内核，不是最终产品边界。

最高目标为什么是 OS核心哲学迁移方法边界
North Star/ 01

Windows/macOS 级别，指的是系统完整性

它不要求第一天重写 Linux、Darwin 或 Windows，也不要求先拥有裸机内核。它要求 NLOS 最终像现代操作系统一样，拥有稳定系统对象、不可绕过的权威、应用平台、桌面、开发工具、兼容承诺和第三方生态。

01通用性

第三方可以运行设计者没有预见的 Application，而不修改内核。

02系统权威

身份、权限、资源、通信、存储和生命周期由系统裁决。

03完整界面

自然语言是首要入口，同时保留 GUI、CLI、API 和逐层控制。

04长期演进

Package、Driver、SDK、兼容性、更新回滚和应用生态共同构成 OS。

HUMAN INTERFACE自然语言桌面 · GUI · CLI · API · 多模态

Why an OS/ 02

智能体系统正在重演计算机系统史

当资源昂贵、任务并发、主体互不信任、状态跨越故障时，应用库无法替代系统层。Agent 编排正在重新遇到分时、虚存、进程隔离、事务、分布式租约、服务治理和桌面控制曾经解决过的问题。

编排框架解决“怎么组织一次流程”

图、角色、handoff、prompt 和工具链非常重要，但它们主要属于应用与用户态策略。它们不能自行成为全局资源、权限、持久化和故障恢复的权威。

NLOS 解决“谁有权在有限世界中做什么”

它管理 Application、Task、Process、Agent、Fiber、Artifact、Context、Resource 和 Device，并让不同框架成为同一系统中的可替换应用。

规模是压力测试，通用才是宗旨。

万级或 PID 级 Agent 不是为了追求一个华丽数字，而是检验对象模型、调度、隔离、资源和控制是否真的具有系统性。

Core Philosophy/ 03

项目真正的五条轴心

01

概率智能属于用户态，确定性不变量属于系统权威

模型理解、规划和提出行动；Capability、资源上界、generation、唯一提交和副作用 fence 由不可绕过边界强制。

02

控制不需要理解

系统不必理解 Agent 为什么行动，只需机械判断它能否命名目标、是否有权、资源是否足够、版本是否新鲜、效果是否可安全提交。

03

自然语言是首要界面，不是裸 ABI

自然语言先编译为 typed Intent、TaskPlan、Action 和 ControlCommand，再进入授权、准入、执行与 Receipt；prompt 本身不拥有权力。

04

自动与手动控制并重

普通用户从顶层说“完成这个任务”，系统自动拆解和调用依赖；高级用户可以像 Task Manager/Activity Monitor 一样逐层下钻和干预。

05

终局完整，实施克制

架构始终面向完整 NLOS；工程从最小 strict、durable、可恢复的纵切面开始，绝不把设计稿误写成已经实现的生产事实。

Transfer Method/ 04

优先迁移现代系统成熟机制

迁移的是控制回路、隔离边界、状态机和失败语义，不是把传统术语贴到 Agent 上。

A

直接迁移

Process isolation、Capability、Namespace、bounded queue、backpressure、WAL、MVCC、lease/fence、cgroup 与 job control。

B

语义适配

Context working set、token/model slot、语义缓存、Agent checkpoint、Topic interest 与 human attention。

C

NLOS 新机制

typed Intent、semantic provenance/view、EffectPermit、模型不确定性边界和外部副作用未知态。

Boundaries/ 05

哪些话现在不能说

不能说“Agent 就是进程”

Application 包含 Process，Process 承载 AgentInstance，AgentInstance 运行 ExecutionFiber。名称类比不会自动带来地址空间或故障隔离。

不能说“所有 Agent 保持同一信念”

系统保证共享状态、snapshot、对象身份、冲突可见与唯一 canonical commit；语义认识仍是 policy-relative view。

不能说“十万 Agent 正在同时思考”

logical、materialized、runnable、active 和 resident 必须分开计量。规模来自惰性物化与有限工作集。

不能说“设计定案等于实现完成”

当前 v0.5 是规范基线；阶段 B runtime、100K Fiber、可信 UI 和故障证据仍在实施。
