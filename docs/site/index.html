抽象比稀缺更长寿

分时系统诞生于昂贵主机时代，但进程、虚存与权限模型在算力普及后成为现代计算地基。稀缺迫使系统发明正确抽象，富足放大抽象的生态复利。

五层模型取代“Agent 即进程”

Application 包含 Process，Process 承载 AgentInstance，AgentInstance 调度 ExecutionFiber。强故障与资源隔离留在 Process/IsolationUnit，高并发复用留在 Fiber。

Multics 警示与最小权威核

Multics 试图在内核包办一切而折戟。NLOS 坚持机制在内核、语义与策略在用户态：TCB 只守住身份、能力、预算守恒与提交围栏。

Problem/ 02

现有框架全是用户态编排库，没有一个是系统权威

立项压力测试：若可调度算力与上下文翻万倍，现有框架能否同时治理万级并发智能体？议题 #31/#32 竞品横评证实，崩溃根源不在工程调优，而在抽象层级错位——用户态库只能约定流程，无法在进程边界之外强制准入、配额、快照隔离与副作用围栏。

CrewAI~100 量级

顺序与层级角色循环将控制流绑死在同步会话内，缺乏异步 ExecutionFiber 挂起恢复与抢占式就绪队列。

Autopsy · 原生语义围栏缺失

议题 #31/#32 结论：现有框架全部驻留在用户态编排层（Userspace Orchestration），而 NLOS 占据不可绕过的系统级权威生态位（TaskSnapshot + CommitPermit + EffectPermit + ResourceAccount + Capability）。六大失效模式的逐项闭合与证据见 支撑与验证 · 宗旨验证 与 执行与控制 · 任务一致性。
