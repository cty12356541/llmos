## 2. 核心实现与安全不变量清单

1. **12 通道与双模式导包兼容**：[common.py](../../../sdk/python/nlos_sdk/common.py) 维护 12 个 `SABI_V1_CHANNELS` 条目，并通过 `_ensure_gen_python_path()` 兼顾源码树直跑与 wheel 独立安装；校验 `non_critical_extension_ids <= 32`、拒绝未知 `major` 及任意 `critical_extension_ids`（含 `0` 与非 `0`）。
2. **持久认证会话与防泄漏加固**：[local_rpc.py](../../../sdk/python/nlos_sdk/local_rpc.py)、[principal_session.py](../../../sdk/python/nlos_sdk/principal_session.py)、[_signing.py](../../../sdk/python/nlos_sdk/_signing.py) 与 [service_directory.py](../../../sdk/python/nlos_sdk/service_directory.py) 补齐 `is_usable`/`is_in_flight`、异步上下文管理、连接毒化拒绝复用提示重连、显式 `IncompleteReadError`/`TimeoutError`/`DecodeError` 脱敏包装、`Ed25519Signer` 零 seed `repr` 泄漏，以及 `IpcError` 重试调用上下文绑定。
3. **共享基类与 5 个新客户端**：
   - [_client_base.py](../../../sdk/python/nlos_sdk/_client_base.py)：统一 `SabiServiceClientBase`、`SabiServiceError`、`service_requirement()`、64 KiB 控制载荷上限检查、同 `idempotency_key` 与负载摘要的 `validate_retry_attempt` 校验。
   - [wait.py](../../../sdk/python/nlos_sdk/wait.py)：`WaitClient` 覆盖 `register_wait`/`inspect_wait`/`list_waits`/`cancel_wait`/`notify_commits`（含语义别名与 `WaitStateCode` fail-closed 解码）。
   - [operation.py](../../../sdk/python/nlos_sdk/operation.py)：`OperationClient` 覆盖 `query`/`cancel` 及 `OperationLifecycleState`，`OperationStatus.__repr__` 脱敏 `receipt_id` 原始字节。
   - [llm_gateway.py](../../../sdk/python/nlos_sdk/llm_gateway.py)：`LlmGatewayClient` 覆盖 `chat`（`llm_chat`）/`query_budget`/`attenuate_budget`/`record_external_usage`；严格使用 `LlmUsage` 对应线端 `LlmUsageWire`，强制 64 KiB 载荷上限及 side-effecting 方法显式 `idempotency_key` 与正 `deadline_monotonic_ns`。
   - [tool_sandbox.py](../../../sdk/python/nlos_sdk/tool_sandbox.py)：`ToolSandboxClient` 覆盖 `list_tools`/`invoke_tool`；校验 `effect_class` 与 `COMPENSATABLE` 的 `compensation_handler` 非空，强制 `invoke_tool` 显式 `idempotency_key`、`deadline_monotonic_ns` 与 64 KiB 上限。
   - [blob_reference.py](../../../sdk/python/nlos_sdk/blob_reference.py)：`BlobReferenceClient` 覆盖 `mint_reference`/`read_reference`/`release_reference` 与 URI 解析/格式化；前置强制 16B 非零 `recipient_principal_id`（字段 8）、`1 <= max_chunk_bytes <= 65408`、`ReadReferenceResult <= 65536`、块对齐 `offset` 检查、逐块 SHA-256 恒定时间校验、holder 错配 fail-closed 拒绝，且 `ReadReferenceResult.__repr__`/`INTEGRITY_ERROR` 异常文本绝不携带原始 blob/chunk/digest 字节。
4. **打包验证修复**：[verify_wheel.py](../../../sdk/python/scripts/verify_wheel.py) 按 `sys.platform == "win32"` 选择 `Scripts/python.exe` 或 `bin/python`，剥离 `PYTHONPATH` 并在源码树外 `cwd=tmp` 运行 27 个模块与 exports 探针。
